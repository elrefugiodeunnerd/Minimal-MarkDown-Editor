# Minimal-MarkDown-Editor

Un editor de MarkDown minimalista hecho por Claude Code (porque no sé programar y quería algo que se ajustara a mis necesidades)

No busco darme el mérito, no lo hice yo, lo hizo Claude, solo quería quitar esa pequeña fricción de mi vida.

Está disponible tanto en AppImage como en .exe para Windows Legacy (8.1/8/7) y para Windows actual (10/11).

Está hecho en Electron para la comodidad de la multiplataforma.
